## 🎯 Objetivo

Construir um site estático com múltiplas páginas e navegação interna, utilizando conceitos básicos de front-end com HTML5, CSS3 e JavaScript.

---

## 🧠 Funcionalidades

- Página inicial com imagem principal
- Página de login simples
- Páginas informativas: sobre, serviços, contato
- Página de erro `404.html`
- Redirecionamento para usuários não identificados
- Estrutura responsiva com imagens e layout limpo

---

## 🚀 Como Executar

1. Baixe ou clone o projeto:
```bash
git clone https://github.com/SeuUsuario/web-trabalho-I.git
cd web-trabalho-I
```

2. Abra o arquivo `index.html` em seu navegador.
